# 무료 라이브러리 덱 등록

`free-decks.sql`은 현재 BASIC 카드의 앞면과 뒷면으로 구성한 세 무료 덱을 등록한다. 기존 수도 100장의 카드 내용과 Wikidata 참조는 유지하고 영어 기초 100장과 토익 업무 어휘 200장을 추가했다. 세 덱 모두 무료 제공 대상이며 가격이나 구매 조건은 없다.

| 덱 | 카드 수 | 출처 | 이용 조건 |
|---|---:|---|---|
| 영어 기초 어휘 100 | 100 | NGSL 1.2 | CC BY-SA 4.0 |
| 토익 업무 어휘 200 | 200 | TSL 1.2 | CC BY-SA 4.0 |
| 세계 수도 100개 | 100 | Wikidata, 2026-10-01 조회 | CC0 1.0 |

영어 목록의 저작자, 원본 URL, 변경 사실과 라이선스는 [콘텐츠 출처](content/README.md)에 정리했다. 영어 덱의 설명에도 출처와 저작자, 라이선스 링크를 넣어 앱에서 덱을 조회하거나 개인 덱으로 복사한 뒤 확인할 수 있다. 수도 카드마다 Wikidata의 국가와 수도 entity를 주석으로 보존했다. 현재 수도가 여러 개로 남은 항목은 제외했으며 전체 국가 목록이나 중요도 순위가 아니다.

## 실행

MySQL 8.4에서 card의 V4 migration을 적용한 뒤 저장소 루트에서 새 mysql batch session으로 실행한다. 연결 정보와 DB는 환경에 맞게 지정한다. 임시 테이블 생성과 대상 테이블의 조회 및 INSERT 권한이 필요하며 stored routine을 만들지 않는다.

```sh
mysql --default-character-set=utf8mb4 --database=<DB> < scripts/sql/library/free-decks.sql
```

첫 등록은 `published = TRUE`여서 실행 후 라이브러리에 노출된다. 배포 시 자동 실행하는 Flyway 경로에 넣지 않았으며 운영 DB에는 별도로 실행해야 한다. 운영 실행 전 연결 대상과 학습용 뜻 및 표기를 검수한다. `--force`를 사용하지 않고 오류가 나면 원인을 확인한 뒤 새 연결에서 재실행한다.

## 재실행과 충돌

- 이름과 카드 전체가 같은 덱이 이미 있으면 ID와 게시 상태, 설명 및 정렬 순서를 유지한다. 기존 수도 초안이 미게시라면 이 SQL을 재실행해도 다시 게시하지 않는다.
- 없는 덱만 등록한다. 같은 이름의 덱이 여러 개이거나 카드 개수, position 또는 앞면 및 뒷면이 다르면 오류로 중단하며 기존 내용을 덮어쓰지 않는다.
- named lock으로 같은 SQL의 동시 실행을 직렬화하고 기존 덱은 `LibraryService.copy`와 같은 row lock을 사용한다. 세 덱의 신규 저장은 하나의 transaction이며 실패하면 함께 rollback한다.
- SQL 편집기가 오류 뒤에도 계속 실행하더라도 최종 카드 검증이 실패하면 rollback한다. 실행 후 결과로 ID, 이름, 게시 여부와 카드 수를 반환한다.

이름으로 기존 덱을 식별하므로 운영자가 덱 이름을 바꿨다면 재실행 전에 기존 ID를 확인해야 한다. 원본 덱의 등록은 이미 복사된 개인 덱과 학습 기록을 변경하지 않는다. 게시 상태를 바꾸는 운영 작업도 대상 원본 덱의 row lock을 사용한다.

## 검증

`LibrarySeedIntegrationTest`가 MySQL 8.4에서 첫 등록과 카드 순서, 재실행, 기존 수도 덱 보존, 수정 내용 및 중복 이름 충돌, 저장 실패의 rollback과 동시 등록을 검증한다.

```sh
./gradlew test --tests '*LibrarySeedIntegrationTest'
```
